# Decision explanation examples

Generated by `python run_demo.py`. Each example shows the input, the rules that fired, the output, and the audit trail.

## 1. Happy path: approved

A complete, valid salaried application. Mandatory checks pass, the credit bureau returns 720, the loan-to-income ratio is 0.33, and the conditional self-employed rule is skipped.

**Input**
```json
{
  "applicant_id": "APP-1001",
  "full_name": "Asha Rao",
  "age": 30,
  "income": 60000,
  "pan": "ABCDE1234F",
  "loan_amount": 20000,
  "employment": "salaried"
}
```

**Output**
```json
{
  "request_id": "req_2a48cab79fe1",
  "status": "APPROVED",
  "retry_count": 0,
  "decision": "APPROVE",
  "reasons": [],
  "rule_trace": [
    "pan_present: passed - PAN number is required",
    "minimum_age: passed - Applicant must be at least 18",
    "minimum_income: passed - Income must be at least 20000",
    "credit_score_minimum: passed - Credit score must be at least 650",
    "loan_to_income_ratio: passed - Loan must be at most half of annual income",
    "self_employed_documents_verified: skipped - skipped: condition employment eq 'self_employed' is not true"
  ]
}
```

**Audit trail (stage / event)**
```
- / received
mandatory_checks / rules_evaluated
credit_check / dependency_attempt
credit_check / dependency_succeeded
risk_rules / rules_evaluated
risk_rules / decision
```

## 2. Invalid input

Missing required fields, a wrong type, a value outside the allowed list, and an unknown field. The request is stored as INVALID and the bureau is never called.

**Input**
```json
{
  "applicant_id": "APP-3003",
  "age": "thirty",
  "income": 50000,
  "loan_amount": 10000,
  "employment": "retired",
  "extra_field": true
}
```

**Output**
```json
{
  "request_id": "req_1a953e3be24b",
  "status": "INVALID",
  "retry_count": 0,
  "errors": [
    "'full_name' is required",
    "'age' must be of type integer",
    "'pan' is required",
    "'employment' must be one of ['salaried', 'self_employed', 'unemployed']",
    "unknown field 'extra_field'"
  ]
}
```

**Audit trail (stage / event)**
```
- / validation_failed
```

## 3. Business rejection: applicant under 18

The minimum-age rule fails with reject. The request stops at the first stage, so no bureau call is made.

**Input**
```json
{
  "applicant_id": "APP-1004",
  "full_name": "Kiran Patel",
  "age": 17,
  "income": 25000,
  "pan": "PQRST5678K",
  "loan_amount": 5000,
  "employment": "salaried"
}
```

**Output**
```json
{
  "request_id": "req_1b8140d03919",
  "status": "REJECTED",
  "retry_count": 0,
  "decision": "REJECT",
  "reasons": [
    "Applicant must be at least 18: actual 17 is not gte 18"
  ],
  "rule_trace": [
    "pan_present: passed - PAN number is required",
    "minimum_age: failed - Applicant must be at least 18: actual 17 is not gte 18",
    "minimum_income: passed - Income must be at least 20000"
  ]
}
```

## 4. Manual review, then reviewer approves

The bureau returns 600, below the 650 minimum. That rule says manual_review, so the request waits for a person. The reviewer's decision is appended to the reasons and the audit trail.

**Input**
```json
{
  "applicant_id": "APP-2002",
  "full_name": "Meera Iyer",
  "age": 42,
  "income": 60000,
  "pan": "LMNOP9012Q",
  "loan_amount": 15000,
  "employment": "salaried"
}
```

```json
{
  "request_id": "req_3d93387ee16c",
  "status": "APPROVED",
  "retry_count": 0,
  "decision": "APPROVE",

    "Credit score must be at least 650: actual 600 is not gte 650",

    "pan_present: passed - PAN number is required",

    "loan_to_income_ratio: passed - Loan must be at most half of annual income",
    "self_employed_documents_verified: skipped - skipped: condition employment eq 'self_employed' is not true"
```

**Input**

```json
  "age": 30,
  "income": 60000,

}
```
